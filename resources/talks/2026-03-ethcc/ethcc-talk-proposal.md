Title: Bringing Ethereum values to our wallets
Short summary:
How do we make sure the tough, ethos-driven, cypherpunk-centric design decisions that have gone into Ethereum protocol design actually make it all the way to end users? Wallets are the last-mile problem of Ethereum values.

Abstract:

How do Ethereum values (security, privacy, self-sovereignty, transparency, etc.) manifest in wallets?
A lot has gone into protocol research to ensure its decentralization and censorship resistance, but such efforts are meaningless if users can't benefit from these properties in practice. Wallets are the "last mile" problem where such efforts need to happen.

This talk goes over a comprehensive set of wallet features that empower the user to benefit from these values. It introduces Walletbeat, a project that aims to create incentives for wallets to compete on bringing these to market.

Impact:

The audience will come away with a framework around Ethereum's timeless values, and how they map onto wallet features. They will understand that protocol design can't be done in a vacuum, and adoption of protocol features (e.g. EIP-7702) needs to take into consideration wallet adoption, not just client/Ethereum node software.
