## Project

Walletbeat is the L2BEAT of wallets. We evaluate wallets across five core attribute groups: privacy, security, self-sovereignty, transparency, and ecosystem alignment. The same values Ethereum upholds. Just like L2BEAT, we also have a stage system, 0, 0.5, 1, and 2.

## Mission

Walletbeat’s mission is simple: Push the Ethereum wallet ecosystem forward towards Ethereum values. Walletbeat’s vision is a wallet ecosystem that is secure, private, self-sovereign, open, and interoperable.

User’s funds are safe, wallets don’t spy on them, the user has full control at all times, and the wallet helps users what the wallet does, and can enjoy all the features Ethereum has to offer.

Walletbeat envisions a wallet ecosystem where the Ethereum community and the Foundation are aligned. We sit in between wallets and the Ethereum Foundation, working to close that gap and raise the bar on both sides.

## How to achieve it

We achieve this by advocating for why these values matter. Setting clear examples of how these values look like in real wallets. Creating incentives for wallets to improve.
