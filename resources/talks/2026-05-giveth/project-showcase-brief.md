## The Problem

The Ethereum wallet landscape lacks a neutral source of truth. Wallets compete on flashy features, not on Ethereum values, such as security, privacy, self-sovereignty, and transparency.

## The Solution

Walletbeat is an open-source public good dedicated to bringing transparency to the Ethereum wallet ecosystem.

As L2BEAT has done for L2s, Walletbeat does for wallets: providing objective, verifiable evaluations that help users make informed decisions.

## Our Values

Walletbeat evaluates software and hardware wallets across dozens of documented attributes following Ethereum values: security, privacy, self-sovereignty, transparency, and ecosystem.

Every evaluation is backed by publicly reviewable data in our GitHub repository, cross-referenced against source code analysis and data collected from wallet teams.

## The Call to Action

Walletbeat is committed to credible neutrality. We refuse funding from wallet-related entities.

Your funding supports filling data gaps across existing listings, onboarding new wallets, expanding hardware and embedded wallet coverage, and improving the evaluation framework.

Every contribution helps keep Walletbeat comprehensive, current, and useful for Ethereum users.

Thank you for your support and for supporting public goods in Ethereum.
