Is your wallet really open source? 👀

We went around @EFDevcon asking people one question:

"What's your number one complaint about wallets?"

@ottokekalainen on why you should be able to build your wallet from source.

---

A public GitHub repo is a good start.

The problem?
You can't tell if the wallet you download from the Chrome Web Store was actually built from that code.

---

That's where reproducible builds come in.

Anyone can build the wallet from its public source code and check that the result matches the version shipped to users.

No need to trust the wallet team's word.

---

At @walletbeat, public source code is a Stage 0 requirement.

We also check for reproducible builds as part of the Release Process attribute.

Ethereum is built to be verifiable. Wallets should be too.
